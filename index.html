Live

A ChatGPT assistant that reads and writes the team's task system

Built at CMJ Business Solutions · 3 pilot users

  • Custom GPT Actions
  • FastAPI
  • SmartSuite API
  • Render

The problem

Staff needed quick answers about tasks, meetings and company data held in SmartSuite, and a faster way to log new work than filling in forms.

What I built

A custom GPT connected through GPT Actions to a FastAPI service on Render, which calls the SmartSuite API. People ask in plain language what is due or what was discussed. The same assistant sorts new work into internal, client or action-item tasks, shows a preview, and creates it only after the user confirms. It can also create tasks in bulk from a meeting. Each request carries the identity of the person asking, so the assistant acts for them.

Result

Queries across roughly 3,300 records fell from 28–55 seconds to about 1–5 seconds once filtering ran on the server. Personal queries fell from 16–22 seconds to 1–5 seconds. A nine-case task-creation test passed, and the assistant is in use with three pilot users.

Live

Automatic follow-up on overdue tasks

Built at CMJ Business Solutions

  • Python
  • SmartSuite REST API
  • Gmail API
  • GitHub Actions

The problem

Overdue tasks were chased by hand. In one snapshot, 369 tasks across 17 owners were overdue, and a single owner held 143 of them.

What I built

A Python job on a GitHub Actions schedule that reads SmartSuite and emails task owners through the Gmail API. It sends three kinds of message: an alert when a task first goes overdue, a Monday and Friday digest, and a Saturday check that end-of-week reports are in. When people reply, a reconcile step updates a status field on the task.

Result

Follow-up runs unattended on a schedule: 63 scheduled runs since early August 2026, 54 of them completed successfully. It was paused during a SmartSuite clean-up and switched back on once the data was ready.

Live

A meeting library that tidies itself, with a human approval gate

Built at CMJ Business Solutions

  • Python
  • Fireflies GraphQL API
  • GitHub Actions
  • Claude

The problem

The meeting-recording library held duplicate recordings and titles that told you nothing about the meeting.

What I built

A tool that finds duplicates (same title, start times within five minutes), keeps the longest copy and proposes the rest for deletion. Nothing is deleted until a person approves it through a GitHub issue. Claude, run headless in the pipeline, renames meetings to a consistent "Topic Meeting with Participant" format. The job runs every 30 minutes.

Result

A library that keeps itself clean on a schedule, with deletion always behind a human decision. Since mid-July 2026 it has made 956 scheduled runs, 886 of them successful, and it tracks 177 meetings.

Tested prototype

SOP assistants for a medical practice's front desk and clinical staff

Built through CMJ Business Solutions for a client medical practice

  • NotebookLM
  • Gemini Gems
  • Markdown
  • Test suites

The problem

Staff procedures were spread across dozens of separate documents. Staff needed correct answers quickly, from an assistant that does not guess.

What I built

Two assistants: one over 10 clinical-operations SOPs and one over 27 front-desk SOPs, merged into 10 knowledge sets. I converted the source documents to clean markdown, wrote the assistant instructions and built a test set for each. The assistants flag documents that are still drafts and refuse to invent live data.

Result

The clinical assistant scored 21 pass, 3 partial and 0 fail on 24 questions. The front-desk assistant scored 25 pass, 1 partial and 0 fail on 26 questions. Testing also exposed real conflicts between the practice's own documents, and the clinical assistant worked out from several documents that a process owner had left.

Deployed

A WhatsApp personal assistant that runs a business owner's calendar

Built at CMJ Business Solutions for its founder

  • FastAPI
  • WhatsApp Cloud API
  • GPT-4o
  • Whisper
  • Google Calendar
  • Gmail API
  • APScheduler
  • SQLite

The problem

A busy owner needed to manage their day from the app they already use all day, without opening a calendar.

What I built

A FastAPI service on a Linux VPS that receives messages through the Meta WhatsApp Cloud API. Text or voice notes (transcribed with Whisper) go to GPT-4o with function calling, which creates, finds, updates and cancels Google Calendar events. It sends scheduled reminders, and it scans Gmail for calendar invites and asks on WhatsApp whether to add them. It replaced my earlier Telegram, n8n and Fibery version of the same assistant.

Result

Running continuously as a systemd service behind Traefik, handling both typed and spoken requests.

Prototype

A WhatsApp exam tutor for final-year engineering students

Personal project · for final-year engineering students

  • FastAPI
  • Claude
  • ChromaDB
  • Whisper
  • WhatsApp Cloud API
  • SQLite

The problem

Students revising for finals need answers based on their own course material, not generic answers from the internet.

What I built

A WhatsApp bot with retrieval over course PDFs, one ChromaDB collection per course. It reads photos of questions with vision OCR, transcribes voice notes with Whisper and remembers each student's conversation. Claude writes the answers, with prompt caching to control cost and a fallback if a reply is refused.

Result

A complete, working build, ready to be loaded with the real course material.

How I build

Reliable automation comes from where you draw the lines

Instructions, reasoning and execution stay separate

Each job is written down as a workflow. An AI agent decides what to do. Plain scripts carry it out. AI is not asked to do every step, so accuracy holds up as the process grows.

A person approves anything hard to undo

Duplicate meetings are deleted only after a human approves them. New tasks appear as a preview and are created only after a confirmation.

The assistant says when it does not know

My assistants flag draft documents and refuse to invent live data. When sources disagree, they surface the conflict.

Tested before it is trusted

Every assistant gets a written question set scored pass, partial or fail, so weak spots are counted and fixed before anyone relies on it.
